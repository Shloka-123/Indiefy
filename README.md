# Indiefy – Indie Music Discovery Platform

Indiefy is a web application that helps users discover independent music artists and songs. It provides a clean, easy-to-use interface and allows users to quickly find tracks on Spotify.

The platform combines a simple backend with a responsive frontend, demonstrating full-stack development in practice.

## Features

- Browse indie artists and songs  
- Dynamic song listing from a backend API  
- Responsive and clean user interface  
- Open songs directly on Spotify  
- RESTful API powered by Node.js and Express  
- Song data stored in SQLite

## Technology Stack

**Frontend:** HTML, CSS, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** SQLite  
**Integration:** Spotify search redirect
